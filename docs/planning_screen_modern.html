What's different in the modern UI approach

Typography

  • Inter font for all body/UI text — renders cleanly at any size (13/14/16/18px used here)
  • VT323 pixel font kept ONLY for the "LAUNCH" logo in top-left — small intentional pixel flavor without fighting readability
  • Clear hierarchy: 11px uppercase section labels, 13-14px body, 16-18px emphasis
  • Font-variant-numeric: tabular-nums for all numbers — consistent alignment

Color system

  • #FFB84D amber replaces pure gold — warmer, more "ember" feeling
  • Every color has ONE job: amber = money/accents, white-grays = text, reds not needed yet
  • Atmospheric pixel art background kept intact — the game's personality shines through
  • UI uses rgba transparency + backdrop blur — feels layered and modern

Visual treatment

  • Subtle backdrop blur on panels and bars — adds premium feel, keeps atmospheric background visible
  • Thin tier indicator stripes (3px vertical bars) still communicate firework tiers at a glance
  • Rounded corners (4-6px) on interactive elements — modern convention, subtle
  • Clean borders (1px rgba white 6-8% alpha) — present but subtle
  • Gentle hover states — subtle background brightens, border emphasizes

What's preserved from the pixel art direction

  • Atmospheric pixel art background (sky, tree, house, fence, fire pit) — unchanged
  • Tier color system (bronze/silver/gold/cyan) — applied as clean stripe indicators
  • VT323 pixel font as identity marker in the logo
  • All gameplay elements remain pixel art (fireworks, show rendering, character silhouettes for Stage 3)

What's better about this approach

  • Readability solved — Inter works at any size, no more fighting font constraints
  • Density improved — can fit more info per row because text is smaller without being unreadable
  • Feels premium — backdrop blur + proper typography hierarchy + subtle animations
  • Future-proof — standard UI patterns will age well, pixel UI risks looking dated
  • Less work — no need to generate/design custom pixel UI chrome for every element

The split: gameplay = pixel art, UI = modern

  • Fireworks firing (Stage 3) stays pure pixel art particle effects
  • Zone backgrounds stay pixel art — beautiful and cheap to generate
  • Character silhouettes for donation screen stay pixel art
  • UI gets out of the way with clean modern chrome
  • This is the approach most successful indies take (Hades, Celeste, Slay the Spire, the Black Hole game you showed)
